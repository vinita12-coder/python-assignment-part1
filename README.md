# Part 1: Python Basics & Control Flow — Student Grade Tracker

A command-line Student Grade Tracker built using core Python concepts.

## Tasks
- **Task 1:** Data Parsing & Profile Cleaning — cleans raw student data, validates names, prints profile cards
- **Task 2:** Marks Analysis — grade labels, stats, and interactive marks-entry using loops
- **Task 3:** Class Performance Summary — formatted report with pass/fail, topper, class average
- **Task 4:** String Manipulation — essay processing using strip, title, count, replace, split

## Concepts Used
- String methods: strip, title, split, replace, count
- List comprehensions
- for and while loops
- f-strings and formatted output
- Conditionals

## How to Run
```bash
python part1_grade_tracker.py
```
